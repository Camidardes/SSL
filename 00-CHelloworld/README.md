# 00-CHelloworld
## Descripcion
Primer programa en C para la materia Sintaxis y Semantica de los Lenguajes.
## Objetivo
Compilar y ejecutar un programa que imprima "Hello World"
## Archivos
- hello.c
  
## Compilación
El programa fue compilado utilizando el compilador GCC con el siguiente comando:
gcc hello.c -o hello
## Ejecución
El programa se ejecutó con:
./hello
Salida obtenida:
Hello, world!
## Redirección de salida
Se redireccionó la salida al archivo output.txt con:
./hello > output.txt
## Compilador utilizado
- Compilador: GCC
- Versión: gcc.exe (Rev14, Built by MSYS2 project) 15.2.0
- Estándar soportado: C17 (compatible con versiones anteriores como C11)
